# GenMitra Roadmaps: complete set

157 SVG roadmaps in 8 folders. Every roadmap has five levels: Beginner, Intermediate, Advanced, Practice and Expert.
Start each folder with the file that ends in master-roadmap (or 01), then follow the numbered files in order.
Shaded chips mark interview problems (DSA) or projects to build (all other folders).

Latest-version badges were verified on 13 Oct 2026 against npm, PyPI and official sources. Python 3.15, C++26, Java 25 LTS and 27 reflect current releases.
